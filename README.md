# Мои чеки — Android 0.1

Приложение для фотографирования чеков и подготовки письма с расходами за месяц.

## На телефоне
1. Установите MoiCheki-debug.apk и откройте «Мои чеки».
2. В «Почта получателя» сохраните рабочий адрес.
3. Нажмите «Получен аванс», введите сумму. Можно добавить несколько авансов.
4. Выберите месяц стрелками, нажмите «Сфотографировать чек», сделайте снимок и подтвердите его в камере. Введите сумму и описание.
5. Нажмите на запись для просмотра фотографии. Удерживайте для изменения суммы/описания или удаления.
6. «Отправить чеки за месяц» открывает выбор приложения. Выберите почту, проверьте адрес, вложения и отправьте письмо.

Отправка не выполняется автоматически; приложение не получает пароль от почты и не отмечает письмо как доставленное. Суммы вводятся вручную. Выбранный месяц определяет месяц отчёта, дата съёмки сохраняется отдельно.

## Хранение
SQLite и оригиналы JPEG находятся в приватном хранилище приложения, по месяцам. Интернет для ведения архива не нужен. Камера открывается по нажатию через установленное приложение камеры. Фоновая съёмка отсутствует.
Удаление приложения или очистка его данных удаляет архив. Автоматического облачного резервирования в версии 0.1 нет: сохраняйте отправленные фотографии отдельно. При большом объёме вложений почта может отклонить письмо; приложение предупреждает при объёме свыше 18 МБ.
Это перечень расходов и фотографии, а не заполненная бухгалтерская форма АО-1.

## Исходники в VS Code / Windows
Распакуйте проект в C:\Users\user\MoiCheki и откройте эту папку через File → Open Folder.
Нужны JDK 17, Android SDK (platforms;android-35 и build-tools;35.0.0), Gradle 8.9.
Укажите ANDROID_HOME на вашу папку SDK, затем в терминале PowerShell:

```powershell
gradle assembleDebug
```

Результат: app\build\outputs\apk\debug\app-debug.apk.
В репозитории предусмотрен .github/workflows/android.yml: сборка после push или ручного запуска, APK в артефакте MoiCheki-debug. Для первой публикации создайте отдельный репозиторий и загрузите содержимое этой папки с сохранением структуры.

## Ограничения проверки
Успешная сборка не заменяет проверку на реальном телефоне. Проверьте: съёмку и отмену снимка, сохранение после закрытия приложения, разные месяцы, несколько авансов, редактирование, удаление, открытие фото и наличие всех вложений в почте.
Debug APK предназначен для первоначального тестирования. Для обновлений с сохранением данных необходимо использовать тот же ключ подписи; не удаляйте установленное приложение ради обновления.
